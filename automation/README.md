# Truth Explains Automated Production Studio — Foundation

Reusable, stateful pipeline derived from the validated EP03 workflow.

Approved script → accuracy → Aunt Truth voice guard → direction/casting → narration
→ timing → visual plan → generation manifest → identity/cost gate → generation
→ music/SFX → assembly → render QA → YouTube/TikTok/Instagram derivatives → release package.

This foundation cannot spend credits or publish. EP03 is the golden reference.
After EP03 is rendered, validated provider-generation, assembly and post-render QA
behavior should be promoted into these stages rather than guessed beforehand.
