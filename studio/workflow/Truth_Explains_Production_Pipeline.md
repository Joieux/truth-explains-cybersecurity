# Tool Responsibilities

## Claude

Purpose:

- Script writing
- Cinematic beats
- Emotional goals
- Scene descriptions

Output:

- EP02_script.md
- EP02_cinematic_beats.md

---

## ChatGPT

Purpose:

- Still image prompts
- Runway prompts
- Camera movements
- Sound design notes
- YouTube metadata

Output:

- EP02_still_image_prompts.md
- EP02_runway_prompts.md

---

## Runway

Purpose:

Animate still images.

Output:

```
scene_01.mp4
scene_02.mp4
scene_03.mp4
scene_04.mp4
scene_05.mp4
```

Motion Rules:

- Slow push-ins
- Gentle parallax
- No shaking
- No glitch effects

---

## DaVinci Resolve

Purpose:

Assemble:

- Runway clips
- Voiceover
- Music
- Sound effects
- Subtitles

Output:

```
Truth_Explains_EP02.mp4
```
