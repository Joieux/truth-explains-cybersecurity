## HOW CHARACTER CONSISTENCY WORKS IN RUNWAY

Runway Gen-4 uses a **character reference image** to keep Auntie Truth looking
identical across every clip. Do this once before you generate anything:

**STEP 1 — Generate the character reference image**
Use the prompt below in Runway's image generator (or Midjourney/DALL-E).
Save the result as: `auntie-truth-reference.png`

**STEP 2 — Upload the reference for every clip**
In Runway Gen-4, click "Character Reference" and upload `auntie-truth-reference.png`
before generating each clip. This locks her face, hair, and style across all 9 clips.

**STEP 3 — Settings for every clip**
- Model: Gen-4 Turbo (5 credits/sec — most cost-effective)
- Duration: 8 seconds
- Resolution: 1080p
- FPS: 24
- Mode: Text-to-Video (with character reference image attached)
