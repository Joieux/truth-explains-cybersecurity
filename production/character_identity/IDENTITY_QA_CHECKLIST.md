# Character Identity QA Checklist

## Source

- [ ] Canonical master references supplied.
- [ ] Correct identity version used.
- [ ] Reference hashes match.
- [ ] No generated scene was used as the primary identity source.
- [ ] No reference chaining occurred.

## Face

- [ ] Same recognizable person.
- [ ] Face shape consistent.
- [ ] Eyes consistent.
- [ ] Nose consistent.
- [ ] Lips consistent.
- [ ] Jaw consistent.
- [ ] Cheek structure consistent.

## Age and skin

- [ ] Apparent age consistent.
- [ ] Skin tone consistent.
- [ ] Lighting changes did not become identity changes.

## Hair and body

- [ ] Natural hairline consistent.
- [ ] Hairstyle uses an approved variant when changed.
- [ ] Build consistent.
- [ ] Body proportions consistent.

## Multi-character scenes

- [ ] Separate canonical references supplied for each recurring character.
- [ ] Characters remain visually distinct.
- [ ] No facial blending.
- [ ] No identity swapping.

## Video

- [ ] Opening frame passes.
- [ ] Midpoint passes.
- [ ] Final frame passes.
- [ ] Facial turns remain stable.
- [ ] Speaking remains stable.
- [ ] Motion does not alter identity.

## Disposition

- [ ] PASS
- [ ] REVIEW
- [ ] REJECT

Rejected material must never become identity-reference material.


## Text and signage

- [ ] Incidental reference-sheet text was not copied into the scene.
- [ ] Clothing, books, laptops, mugs, posters, signs, and screens contain no unnecessary readable text.
- [ ] Any required readable text is intentional and script-driven.
- [ ] No unnecessary signage was introduced.
- [ ] Approved identity symbols remain consistent.
- [ ] Malik's jacket symbol may remain when that approved wardrobe variant is used.
